# Stay Stories — Property Films

A responsive, single-page website concept for a premium property video agency serving holiday homes, villas, and boutique stays.

## Files
- `index.html` — website content and page structure
- `style.css` — responsive design and visual styling
- `script.js` — mobile navigation and footer year

## Publish with GitHub Pages
1. Create a GitHub repository named `stay-stories`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment to finish. GitHub will show the published site URL in the Pages section.

## Before publishing
- Replace `hello@yourdomain.com` in `index.html` with your real business email.
- Replace the demo images with images/video that you own or have permission to use.
- The portfolio section clearly labels its images as visual references; only present real client work as client work.
- This is a static portfolio website. It does not include booking, payments, a database, or an AI video-generation backend.
